# Cognibloom Collective Website

This is a Next.js 14, Tailwind CSS v4, and TypeScript website for **Cognibloom Collective**, a non-profit organization focused on forest conservation, organic farming, and eco-literacy.

## Tech Stack
- **Framework:** Next.js 14 (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS v4
- **Icons:** `lucide-react`
- **Utilities:** `clsx`, `tailwind-merge`

## Getting Started

First, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Folder Structure
- `src/app/` - Page routes and layouts.
- `src/components/` - Section modules and UI elements.
- `src/layouts/` - Navbar and Footer templates.
- `src/constants/` - Static configurations and text contents.
- `src/types/` - TypeScript interface mappings.
- `src/hooks/` - Window resize, scroll tracking, and viewport observers.
- `src/utils/` - Global classes and utilities.
